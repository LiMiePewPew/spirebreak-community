# Website Showcase Media

Current selection captured October 4, 2026 from game build
`8765f7a63de2786072cce052e35f40a4376e536b`, using Godot 4.7.1 and
the production Compatibility renderer. It shows the orbital arena and distant
planet in the current game source.

Foundation, Fortified and Ascendant are staged example loadouts, each captured
in a fresh run on the opening arena. Combat uses the Ascendant example loadout
and the production Wave 10 encounter. The eight-second clip runs at normal
simulation speed with unmodified combat rules after fixture setup. These are
presentation examples, not footage of one continuous player run.

The production 3D viewport is captured directly, excluding UI. No geometry,
objects, lighting or effects are added in image post-production. All selected
frames were inspected for public use: game imagery only, no debug panels,
private paths, credentials, player identifiers or internal development notes.

Native captures are 2275×1164. WebP and AVIF derivatives are 960×491 and
1920×982, without upscaling. The silent H.264 clip is 1600×818, 30 fps,
240 frames, yuv420p, with fast-start metadata; it is shared by the background
and gameplay player. Assets use `/media/showcase/orbital-2026-10-04/` so
existing browser/CDN caches cannot substitute the previous arena.

The older September 22 captures remain at their historical URLs, but are no
longer used by the homepage, gameplay player or social preview. Dated
changelog articles remain unchanged.
